# Как запустить Studly

Проект состоит из двух частей:

| Часть | Папка | Технологии | Адрес |
|---|---|---|---|
| Бэкенд (API) | `backend/` | Python, FastAPI, MySQL | http://127.0.0.1:8000 |
| Фронтенд | `studly/` | React 19, React Router | http://localhost:3000 |

Нужно установить: **Python 3.11+**, **Node.js 18+** (с npm) и **MySQL 8**.

---

## 1. База данных (один раз)

```powershell
cd D:\studly\backend
mysql -u root -p --default-character-set=utf8mb4 < database\schema.sql
```

Создастся база `studly_db` со всеми таблицами. Если база уже была — ничего пересоздавать не нужно:
при старте сервер сам добавит недостающее (роль администратора, таблицы для кабинета родителя,
коды приглашений, достижения).

## 2. Настройки бэкенда (один раз)

Скопируйте `backend\.env.example` в `backend\.env` (если файла `.env` ещё нет) и проверьте значения:

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=ваш_пароль_от_MySQL
DB_NAME=studly_db
CORS_ALLOWED_ORIGINS=http://localhost:3000
JWT_SECRET=любая_длинная_случайная_строка
PORT=8000
OPENAI_API_KEY=        # необязательно — без ключа AI-план строится по вашим данным
GEMINI_API_KEY=        # необязательно
```

## 3. Запуск бэкенда

```powershell
cd D:\studly\backend
python -m venv venv              # только в первый раз (папка venv уже есть — пропустите)
.\venv\Scripts\activate
pip install -r requirements.txt  # в первый раз и после обновлений
python main.py
```

Проверка: откройте http://127.0.0.1:8000/api/health — должно быть `{"status":"healthy"}`.
Документация API: http://127.0.0.1:8000/docs

**Демо-данные (по желанию):**
```powershell
python scripts\create_seed.py
```
Создаст ученика `test@studly.com` с паролем `test123` и примеры предметов, задач и сессий.

## 4. Запуск фронтенда (в отдельном окне терминала)

```powershell
cd D:\studly\studly
npm install      # только в первый раз
npm start
```

Откроется http://localhost:3000. Если бэкенд запущен на другом адресе — создайте
`studly\.env` со строкой `REACT_APP_API_URL=http://адрес:порт` и перезапустите `npm start`.

## 5. Роли и проверка сценариев

- **Ученик** — регистрация → «Школьник или студент»: предметы, задачи, сессии, таймер, статистика, цели, AI.
- **Родитель** — регистрация → «Родитель или учитель». Ученик берёт код в «Профиле»,
  родитель вводит его в кабинете — и видит те же цифры, что и ученик.
- **Администратор** — самостоятельно зарегистрироваться им нельзя. Назначьте через MySQL:
  ```sql
  UPDATE users SET role = 'admin' WHERE email = 'ваш@email';
  ```
  затем выйдите и войдите заново — откроется «Панель админа».

## 6. Тесты

```powershell
cd D:\studly\backend
.\venv\Scripts\activate
python tests\test_api.py          # тест API, MySQL не нужен

cd D:\studly\studly
npm test                          # тест фронтенда
npm run build                     # сборка в папку build
```

## Частые проблемы

| Симптом | Что сделать |
|---|---|
| «Сервер Studly недоступен» | Бэкенд не запущен или запущен не на 8000 — см. шаг 3 |
| `Access denied for user 'root'` | Неверный `DB_PASSWORD` в `backend\.env` |
| `Unknown database 'studly_db'` | Не выполнен шаг 1 |
| Ошибка CORS в консоли браузера | Добавьте адрес фронтенда в `CORS_ALLOWED_ORIGINS` |
| `email-validator is not installed` | `pip install -r requirements.txt` |
| Вместо русского текста символы вроде `╨Я╨╡╤А…` | Перезапустите бэкенд — он сам исправит такие строки. При импорте SQL всегда добавляйте `--default-character-set=utf8mb4` |
