# Настройка AI для Studly

## Google Gemini (бесплатно) — рекомендуемый вариант

Gemini API от Google доступен **бесплатно** с лимитами запросов.

### 1. Получить API ключ

1. Перейдите на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. Войдите в Google-аккаунт
3. Нажмите «Create API key» → выберите проект или создайте новый
4. Скопируйте ключ

### 2. Добавить в .env

```
GEMINI_API_KEY=ваш_ключ_сюда
```

### 3. Установить пакет (если ещё не установлен)

```bash
pip install google-generativeai
```

### 4. Перезапустить backend

После добавления ключа AI Планировщик будет использовать реальный Gemini для генерации рекомендаций.

---

## Без API ключа

Если `GEMINI_API_KEY` не задан, AI Планировщик работает в **моковом режиме** — возвращает предзаполненные рекомендации на основе данных из БД.

---

## Альтернативы (платные или с лимитами)

| Провайдер | Бесплатный tier | Установка |
|-----------|-----------------|-----------|
| **OpenAI** | $5 при регистрации | `pip install openai`, `OPENAI_API_KEY` в .env |
| **Anthropic Claude** | Ограниченный | `pip install anthropic`, `ANTHROPIC_API_KEY` |
| **YandexGPT** | По запросу | Yandex Cloud API |

Для добавления другого провайдера — отредактируйте `routers/ai_planner.py` и добавьте свою логику в `generate_plan`.
