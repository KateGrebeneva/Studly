                         S T U D L Y
          Веб-приложение для планирования и учёбы

Studly помогает организовать занятия: предметы и задачи, сессии с таймером
Pomodoro, статистика, кабинет родителя и панель администратора. Есть
опциональные функции на базе ИИ (OpenAI / Google Gemini).

Этот файл представляет собой краткое руководство для пользователя: в нём описана 
структура проекта, используемые технологии, а также приведены инструкции по запуску 
проекта на локальном компьютере.


--------------------------------------------------------------------------------
  1. ЧТО НУЖНО УСТАНОВИТЬ ЗАРАНЕЕ
--------------------------------------------------------------------------------

  • Node.js 18+ и npm          — для фронтенда (папка studly)
  • Python 3.10+               — для бэкенда (папка backend)
  • MySQL 8.0+                 — база данных
  • Git                        — если клонируете репозиторий (по желанию)

Проверка в терминале:

  node -v
  npm -v
  python --version
  mysql --version

  3. СТОРОННИЕ БИБЛИОТЕКИ И ВНЕШНИЕ РЕСУРСЫ
--------------------------------------------------------------------------------

  Ниже перечислены основные зависимости. Полный список npm-пакетов
  подтягивается автоматически при «npm install» (сотни транзитивных
  зависимостей — см. package-lock.json).

  ─── Python (backend/requirements.txt) ───

  fastapi              — веб-фреймворк API
  uvicorn              — ASGI-сервер для запуска API
  python-dotenv        — загрузка переменных из .env
  pymysql              — драйвер MySQL
  cryptography         — криптография для PyMySQL
  python-jose          — JWT-токены
  passlib[bcrypt]      — хеширование паролей
  pydantic             — валидация данных
  pydantic-settings    — настройки из окружения
  python-multipart     — загрузка форм
  email-validator      — проверка email
  google-generativeai  — API Google Gemini (ИИ, опционально)
  openai               — API OpenAI (ИИ, опционально)

  ─── JavaScript / npm (studly/package.json) ───

  react                — интерфейс
  react-dom            — отрисовка в DOM
  react-router-dom     — навигация по страницам
  react-scripts        — сборка (Create React App)
  lucide-react         — SVG-иконки

  Пакеты для разработки и тестов:
  @testing-library/react, jest-dom, dom

  ─── Внешние сервисы и файлы (не в репозитории) ───

  MySQL 8+             — хранение данных (устанавливается отдельно)
  Google Fonts         — шрифты Unbounded и Nunito (подключаются из интернета
                         в studly/public/index.html)
  OpenAI API           — генерация планов и тестов (ключ в .env, опционально)
  Google Gemini API    — альтернатива OpenAI (ключ в .env, опционально)

  Без ключей ИИ приложение работает: план строится по данным пользователя,
  а вопросы для закрепления берутся из заготовок.


--------------------------------------------------------------------------------
  4. ЗАПУСК ПРОЕКТА — ПОШАГОВАЯ ИНСТРУКЦИЯ
--------------------------------------------------------------------------------

  Рекомендуемые порты (как настроено в проекте сейчас):

    • Бэкенд (API):     http://127.0.0.1:8000
    • Фронтенд (сайт):  http://localhost:3000
    • MySQL:            localhost:3306 (стандартный порт)

  Откройте три отдельных окна терминала (или вкладки) и выполняйте шаги
  по порядку.


  ┌──────────────────────────────────────────────────────────────────────────┐
  │  ШАГ A. НАСТРОЙКА БАЗЫ ДАННЫХ MySQL                                      │
  └──────────────────────────────────────────────────────────────────────────┘

  1) Запустите службу MySQL.

  2) Создайте базу и таблицы. Из корня репозитория:

       cd backend
       mysql -u root -p --default-character-set=utf8mb4 < database/schema.sql

     (введите пароль пользователя MySQL, если он задан)
     Если база уже была создана раньше — ничего делать не нужно, при старте
     бэкенд сам добавит недостающие таблицы и исправит кодировку.

  3) Заполните тестовыми данными (необязательно, но удобно для первого входа):

       python scripts/create_seed.py


  ┌──────────────────────────────────────────────────────────────────────────┐
  │  ШАГ B. ЗАПУСК БЭКЕНДА (API)                                             │
  └──────────────────────────────────────────────────────────────────────────┘

  1) Перейдите в папку backend:

       cd backend

  2) Создайте виртуальное окружение Python (рекомендуется):

       python -m venv venv

     Windows — активация:
       venv\Scripts\activate

     macOS / Linux:
       source venv/bin/activate

  3) Установите зависимости:

       pip install -r requirements.txt

  4) Создайте файл настроек .env из образца:

       copy .env.example .env          (Windows)
       cp .env.example .env            (macOS / Linux)

  5) Откройте .env в текстовом редакторе и укажите свои данные:

       DB_HOST=localhost
       DB_USER=root
       DB_PASSWORD=ваш_пароль_mysql
       DB_NAME=studly_db

       PORT=8000

       CORS_ALLOWED_ORIGINS=http://localhost:3000,http://127.0.0.1:3000

       JWT_SECRET=придумайте_длинный_секретный_ключ

       OPENAI_API_KEY=          (можно оставить пустым)
       GEMINI_API_KEY=          (можно оставить пустым)

  6) Запустите сервер:

       python main.py

     или:

       uvicorn main:app --reload --host 0.0.0.0 --port 8000

  7) Проверка: в браузере откройте

       http://127.0.0.1:8000/api/health

     Должен вернуться ответ вроде: {"status":"healthy"}


  ┌──────────────────────────────────────────────────────────────────────────┐
  │  ШАГ C. ЗАПУСК ФРОНТЕНДА (сайт в браузере)                               │
  └──────────────────────────────────────────────────────────────────────────┘

  1) В НОВОМ терминале перейдите в папку фронтенда:

       cd studly

     (именно вложенная папка studly внутри корня репозитория)

  2) Установите зависимости (один раз):

       npm install

  3) Если бэкенд запущен не на http://127.0.0.1:8000, создайте файл
     studly/.env со строкой:

       REACT_APP_API_URL=http://адрес:порт

  4) Запустите приложение:

       npm start

  5) Браузер откроет сайт (обычно автоматически):

       http://localhost:3000

     Страницы входа: /login , регистрации: /register


--------------------------------------------------------------------------------
  5. КАК СВЯЗАНЫ ФРОНТ, БЭК И БАЗА ДАННЫХ
--------------------------------------------------------------------------------

       ┌─────────────┐         HTTP + JWT          ┌─────────────┐
       │  Браузер    │  ────────────────────────►  │  FastAPI    │
       │  React      │   http://127.0.0.1:8000     │  backend    │
       │  :3000      │  ◄────────────────────────  │  :8000      │
       └─────────────┘         JSON                └──────┬──────┘
                                                          │
                                                          │ SQL
                                                          ▼
                                                   ┌─────────────┐
                                                   │   MySQL     │
                                                   │  studly_db  │
                                                   └─────────────┘

  • После входа фронтенд сохраняет JWT в localStorage (ключ studly_token).
  • Каждый запрос к API отправляет заголовок: Authorization: Bearer <токен>
  • CORS в .env должен разрешать origin фронтенда (localhost:3000).
  • Если видите «Сервер Studly недоступен» — проверьте, что бэкенд запущен
    и порт совпадает с адресом во фронтенде (REACT_APP_API_URL).

--------------------------------------------------------------------------------
  7. ИИ-ФУНКЦИИ (ПО ЖЕЛАНИЮ)
--------------------------------------------------------------------------------

  В backend/.env добавьте один или оба ключа:

    OPENAI_API_KEY=sk-...
    GEMINI_API_KEY=...

  Перезапустите бэкенд после изменения .env.

  Без ключей AI-планировщик всё равно работает — по вашим реальным данным.


--------------------------------------------------------------------------------
  8. СБОРКА ДЛЯ ПРОДАКШЕНА (кратко)
--------------------------------------------------------------------------------

  Фронтенд:
    cd studly
    npm run build
    Папка build/ — статические файлы для веб-сервера (nginx, IIS и т.д.)

  Бэкенд:
    uvicorn main:app --host 0.0.0.0 --port 8000
    (без --reload на боевом сервере)

  Не забудьте:
    • сменить JWT_SECRET на уникальный;
    • указать реальные CORS_ALLOWED_ORIGINS (ваш домен);
    • задать REACT_APP_API_URL перед сборкой фронтенда.
